# 使用与回退

应用安装在 `~/Applications/Phosphene Go.app`，本地源码在 `~/tools/phosphene-go`，开发分支为 `feature/mygo-local-wallpaper`。

## 常用操作

- 资料库：批量导入、预览、读取媒体信息、重命名、加入/移出轮播、删除副本。
- 播放列表与显示器：上移/下移顺序、统一设置播完切换或指定秒数、查看各屏位置。
- 设置：接电锁屏亮屏、登录启动、打开系统墙纸设置和资料库目录。
- 关闭主窗口：管理端保留菜单栏。菜单栏“打开资料库”可重开。
- 完全退出：菜单栏选择“退出管理端（壁纸继续播放）”。扩展仍由系统宿主管理。

视频以原始画质复制，不重新编码。删除仅针对新应用的副本，源文件保留。空列表不会主动清黑已经在显示的桌面。

## 回退

旧 `/Applications/Phosphene.app` 及原素材保留。要回退，在系统墙纸设置中选择原 Phosphene 的壁纸条目；若需要旧版的播放修复逻辑，再手动打开 `~/Applications/双屏壁纸一键播放.app`。

新应用与旧应用使用不同的 Bundle ID、容器和通知，不修改旧应用的列表与暂停偏好。开发前的系统选择备份保存在本机源码 `build/wallpaper-before.plist`，仅供排查和核对，不需要手工修改或覆盖系统墙纸索引。
